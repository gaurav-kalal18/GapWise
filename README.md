# GapWise

AI-Based Personalized Job Skill Gap Analyzer

GapWise analyzes a candidate's current skills, compares them with
the competency requirements of a target job role, identifies and
prioritizes skill gaps, and generates a personalized path for
improving job readiness.

## Project Goals

- Extract meaningful skills from resumes
- Understand job requirements
- Perform semantic skill matching
- Identify and prioritize skill gaps
- Generate personalized learning paths
- Provide explainable recommendations
- Optimize long AI conversations
- Evaluate the reliability of matching decisions

## Architecture

- Frontend: React
- Backend: Node.js + Express
- AI Service: Python
- Database: PostgreSQL

## Development Philosophy

Build incrementally:
Understand → Implement → Test → Evaluate → Improve
